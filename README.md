# auditglob

Audit CSV/TSV glob tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/auditglob/

## Install / run

```bash
git clone https://github.com/theworker02/auditglob.git
cd auditglob
node src/cli.js
node --test
```
